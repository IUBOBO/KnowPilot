## 基线与方案

`main.tsx` 先导入 `index.css` 再导入 `a-theme.css`。亮色两条 `:root` 和暗色两条 `[data-theme="dark"]` 分别同优先级，顺序决定最终值。实际亮色标题 `#183d40`、辅助 `#52686a`，后者同时承担三级和四级文字。暗色也被覆盖。详见矩阵实测。

- 以 `index.css` 的 `:root` 和暗色块为 Token 唯一来源，把需继续使用的品牌、导航和状态值归位。让 `a-theme.css` 保留应用布局兼容并消费 Token。默认保持入口加载顺序；仅确需调整导入时才修改 `main.tsx`。`router.tsx`、`Layout.tsx`、`theme.ts` 为核对与回归入口，默认不改。
- 标题、正文、辅助、强调、真实命中、引用、字段标签和关键数值分别定义。兼容现有 `--ink` 系列和 `--mark-*` 的消费者，先按语义映射，再移除重复定义。普通链接和操作用原有绿；深蓝只用于主动采用的内容重点。用正文容器与局部类表达标题 1/2/3、约 15–16px 阅读字号、段间距和数值对齐规则。避免对全局 `strong`、`a`、`mark` 加一刀切规则。
- 亮色以背景 `#F4F6F6`、卡片 `#FFFFFF`、标题 `#17212B`、正文 `#374151`、重点 `#173E73` / `#EAF1FA`、命中 `#F6E3B4`、品牌 `#087C82` 为候选。辅助 `#64748B` 在白底约 4.76:1，但在页面底约 4.39:1，建议合并为 `#5D6E82` 或按背景独立配对后冻结。
- 暗色先验证独立候选：页面/卡片/次表面 `#12171D` / `#1B232C` / `#232F3B`，标题/正文/辅助 `#ECF2F8` / `#CDD6E1` / `#A2B2C5`，重点 `#B7D4FA` / `#25364D`，命中保留 UX-02 的暖底 `#E9CC87` / 深字 `#382707`。这些是设计候选，真实 CSS 配对通过后才算冻结。错误、警告、成功保留原语义，用实际叠层校验前景和焦点，避免同色半透明背景叠加压低对比度。
- 文件所有权为 `apps/web/src/index.css`、`a-theme.css`、必要 CSS 入口及公共 UI 的表现规范。保持 Modal、ConfirmDialog、ErrorNotice、EmptyState、导航与页头交互，将需要的公共实现改动限制在语义展示。冻结后 UX-04、UX-05 仅读 Token。

## 节点与验收

| 节点 | 实施 | 放行条件 |
|---|---|---|
| N1 | 复测同优先级覆盖，记录实际消费者与背景组合 | 基线复现，完成品牌、内容、状态和证据的角色映射 |
| N2 | 整理单一 Token、显式样式及兼容映射 | 两套主题无重复覆盖。普通字号在实际背景上 ≥4.5:1，暗色含嵌套错误徽标。检查导航、按钮、选中、Tab 焦点和状态辨识 |
| N3 | 验证登录/403、公共空态/错误/弹窗及代表页面 | 保留 UX-01 复核确认和 UX-02 卡片/命中/展开，交付截图、对比度、回归结果。经人工审查并冻结实际主线 SHA、Token 名和用途，随后释放 #49、#50 |

执行 `npm run typecheck` 与 `npm run build -w @knowpilot/web`。浏览器用同数据、同回答、同视口与同主题截图，记录实际命令、退出码和例外。沿用现有独立合成资料与模型替身，正式验收以本任务定向回归为准。G0–G5 全量、真实模型和线上资料不参与。 额外覆盖透明背景合成、链接与交互状态，辅助字号按普通字号测。回滚可独立 revert，按冻结 SHA 重新检查消费者，冻结后变更由协调者串行处理。
