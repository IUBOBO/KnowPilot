- 模型只提出白名单组件、证据编号和需核对的度量，文档标题、页码、原文和记录字段由最终引用表提供。动态摘要和 Markdown 逐行核对已授权引用的完整原文，只允许添加标题、列表和引用标记等格式。Markdown 表必须保持来源中的表头、列次和数据行。每个句内编号都须独立支撑该行，表格编号还须在相同列头下支持对应数据行。正文和表格出现错配编号时均降级，底部只保留参与支撑的来源。原文无法核对的转述一律降级到既有正文，与数值写法无关。复制含数值的原文也须保留实测标记；验收门槛或尚未公布的数值、真实但无法核对实测标记的数值只保留既有正文。比较要求同指标、数据集、单位、实验设置和统计口径，指标字段须与元数据字段独立，禁止将设置、数据集、单位等元数据解析为度量结果。明确标为假设、目标、预测或未实测的摘录降级。未达到这些条件会省略结构化比较，仍显示既有正文。字段缺少明确标签或换行无法核对时按无依据降级。字面核对不代表对结论做语义审查。
- 前端新增摘要、Markdown、文档列表、论文、比较表、数值图表、记录、时间线、证据和参考步骤视图。引用链接从当前回答中按 ID 读取服务端引用，依据版本化回调传递 run ID 和定位。Markdown 行内、表格和指标图表引用走相同的回调。宿主拒绝或旧引用缺少版本时，保留旧链接。
