### 事件口径

- 路由识别来自实际的 routeTask/计划构建。追问理解仅在实际改写时生成，续跑恢复仅在读取检查点时生成。查询步骤来自准入的工具事件。证据额度耗尽时只记录明确的「未检索」结果，无候选、子查询参数或检索耗时。补查标记来自现有补查控制。关闭重排、未进入重排的策略和无补查均不生成所对应步骤。重排完成和回退取自检索响应，降级只发类型，不发自由文本。
- 子查询按真实发生顺序显示，只传实际模式、请求模式、文档范围类型、材料类型、候选上限和耗时。查询词、文件路径、来源证据 ID 和工具调用 ID 不进入新增公开过程数据。台账按实际工具类型显示，未经测量的可选字段留空。
- 候选是实际查询在各自窗口内返回的条数，包含逐次重复，与去重的入池数不同。按章节精读使用底层实际检索的候选数。逐段顺序阅读由工具返回已选窗口，候选保留未知。被预算拦下或失败的操作没有由工具产生的候选计量。观察到零时显示 0，未运行或未知有独立提示。文档数是池中去重文档；入池包括恢复后获准的条目。模型计数去重后只统计实际传输调用上下文中已附入的编号条目，不统计无编号相邻块；终稿引用来自已校验回答。
- 新版终态存有同一运行的安全快照，旧回答和旧 SSE 仍兼容。折叠面板默认关闭，失败或取消后保留本次已观测步骤。没有数据库迁移。
- 管理 Trace 的 `trace.read.all` 保持原样。新增字段仅为枚举和数值。Trace 写入及旧行读取均遮蔽工具词、改写原文、自由文本错误和告警。Trace 列表与详情对已有问题只显示「已脱敏」，缺少原始记录时返回空值。提问者可按既有授权从问答历史读取自己的问题原文。既有事实、用户权限、预算和模型设置未变。
