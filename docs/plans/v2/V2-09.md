### N1 私有笔记契约

- v37 只追加三张表。笔记保存编辑正文、标题、标签、版本号和时间。关联运行及引用单独保存，引用保留运行 ID、引用 ID 及可核实的来源定位。原文与引用摘录通过当前来源接口重读。
- CRUD 使用 `/api/v1/research-notes`。登录者只能查询和修改自己的笔记，管理员走同一所有者条件。不存在和非本人 ID 均用 404。修改和删除要求当前笔记 revision，过期 revision 返回 409。
- 问答转笔记只接受作为用户编辑内容的答复或选段，以及本人运行 ID。后端以已落库的引用信息确认来源。来源元数据缺失时保留运行关联，阅读器提示无法重读。
- 迁移和 CRUD 独立于公共文档、知识草稿及索引表。授权矩阵覆盖匿名、本人、其他成员和管理员。笔记权限与来源权限分别重新检查。

### N3 来源重读和继续研究

- 来源保留运行 ID、引用 ID、可核实的来源定位和版本。笔记读取时复核原问答归属及当前资源授权。旧引用缺少可核实的定位、版本或关联字段指纹时保留关联并提示。失效项和变化项不返回定位及标题。
- 文档打开、预览及下载分别复查所有者、文档当前状态和引用版本。授权历史文档只重读保留的引用片段。台账、数据集和期刊复用既有权限和精确查询。新投稿、专利、论文及期刊引用额外比较字段指纹，覆盖只修改关联字段的情况。没有指纹的旧期刊引用仍可按原期间重读，并提示旧字段修订未保留。
- 继续研究使用当前可读文档形成 #8 资料范围。返回检索仅使用当前账号的导航状态预填原笔记标题，等用户主动提交才检索。笔记检索词保存在该导航状态，浏览器地址只保留资料筛选。重新选择资料、清除范围、刷新和浏览器返回都按会话保留资料范围。无法恢复时要求用户重选。进入普通问答会恢复普通会话，显示的历史、重试与续跑同样检查会话归属。
- 完整答复转笔记同时保存答复的依据缺口、适用边界、注意事项和资料矛盾。完整答复或选段中的已验证引用使用「第 N 轮 · E#」标记。右侧来源区使用相同标记定位相应运行。已有编辑正文照原样保留，无法判定具体轮次的旧引用提示按运行核对。完整答复中的代码和公式保留字面内容。
- #10 导出读契约复用 `readResearchNote` 和 `presentResearchNote`，接收当前登录者和笔记 ID。导出候选消费笔记的 `id`、`revision`、`title`、`body`、`tags`、本人运行及当下可读的来源。失效项保留状态提示。原文从现有授权来源按需重读。
- #11 草稿入口沿用同一所有者读契约，未来显式选择需提交的正文与来源，复查 revision 和来源权限，再交接既有知识审核流。私有笔记本身不进入公共索引；审核与公开均由后续 Issue 实施。
