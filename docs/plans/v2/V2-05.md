### 实际改动及取舍

- `EvidenceViewer.tsx` 在已授权的当前 PDF 引文中提供「打开 PDF 预览」。默认显示既有摘录，开启后切换引用会在新原件定位相应物理页。切换侧栏与全屏保留同一引用的页码和缩放。
- `PdfPreview.tsx`、`pdf-preview.css`、`pdf-document.ts` 负责本地 worker、单页绘制和工具栏。物理页从 1 起，源于授权块 `chunk.page`。有 PDF 页标签时另行展示，跳转输入始终使用物理页码。页码缺失或越界时展示原件首页和原因，禁用自动高亮。历史索引或版本无法核对时保留历史片段和原件入口。
- `pdf-text-match.ts` 只在所引物理页进行匹配。问答优先核对来源摘录并使用与授权块一致的字串，检索块可使用服务端返回的原文。文字先规范化 Unicode 和空白。相邻横排文本按几何位置处理跨行、断词和栏间距。每个唯一匹配用 PDF.js 文字层测量矩形，重复、无法确定、无文字层和不可见文字层给出相应提示。高亮用于摘录定位。
- `apps/web/package.json` 与锁文件固定同一套 `pdfjs-dist@5.4.296`。发布包含 `public/licenses/pdfjs.txt` 的 Apache-2.0 许可全文及署名。PDF 代码分块动态加载，worker 随 Web 发布并从同源加载，读取使用既有 `GET /api/v1/documents/:id/file`。浏览器仅在预览开启后读取完整授权响应，设置 `no-store`，取消已关闭或已切换的请求，取消绘制并销毁文档与 worker。预览文件限 64 MiB，每次只绘制当前页，页面 canvas 限 8,192 像素边长、8 MP 和 2× 设备像素比。
- 兼容与回退沿用既有读取及下载。无需数据或协议迁移，回滚撤回本 PR 的前端代码和依赖声明即可。完整原件接口暂不提供 Range，同一原件切换引用或全屏可重新请求。超限原件仍可走原下载入口。内嵌预览以画布显示，已授权摘录继续以文本呈现。加密原件和极端尺寸可回退下载。旋转、竖排、复杂表格/公式、布局冲突或无法使用的字体/CMap 可能无法定位，未以渲染结果反推印刷页或重新 OCR。未做 Chromium 之外的浏览器验收及长时间堆分析。

### 独立审查修正

初始候选 `99027fa8d15275cc0c0f0e0132d0fb3d79851cc3` 的三处定位边界经修正复验。

- 搜索结果的展示摘录可能折叠块内空白，并用省略号标记截断。对无问答引用标识的检索来源，先在折叠空白后的授权块中核对展示摘录，必要时去除用于截断的省略号，匹配必须唯一。如果窗口截在字母或数字单词内部，仅用该块中的真实相邻字符补齐单词。Chrome 验证搜索截断摘录可高亮，同片段重复时降级。同样的摘录用于问答引用时仍按原逐字策略降级，原摘录视图也保持逐字校验。
- PDF.js 的文字流包含默认隐藏的可选图层。只在已知的简单图层于本页显示时允许继续匹配，含隐藏或无法核对的图层时整页降级。画布和高亮采用同一个 display 配置。Chrome 对照测试验证默认关闭的图层仍有索引文字，但画布全白且无高亮。默认打开的图层可正常高亮。
- 几何检查确认是连续折行后，按服务端解析规则直接衔接符合条件的中文文字和全角标点。测试使用内嵌字形、可独立生成的两行 PDF，已在 Chrome 定位跨两行的「中文原文」。额外断言覆盖中西文标点边界，原西文断词、双栏和重复摘录场景通过。

修正后的全部工作区类型检查、Web 生产构建和 PDF 浏览器验收通过，复验含 9 项文字层断言和 23 个真实 worker 启动及回收。原 `verify-auth` 和两条阅读器兼容性命令的记录来自初始候选，修正未更改服务端及旧摘录校验。独立复验和 `13-B.5.pre` 待协调者执行。

复审补充了检索端按块首截断、未附省略号的路径。所有检索摘录统一在授权块的折叠空白文本中核对唯一位置，只有确认截口连着原文中的拉丁字母或数字时才补齐该词。Chrome 复验使用未附省略号的 `Second document with independent te`。同一片段用于检索时定位完整单词，用于问答时只在索引文本标出逐字一致的部分，PDF 页内继续降级。带省略号、重复和隐藏图层等原用例仍通过。

### 不可见原文复验（v1.5）

- N2：纯合成 PDF 在文字绘制阶段应用裁剪路径，另一页在文字上方绘制不透明白色矩形。修正前 Chrome 确认裁剪页画布全白，但仍显示一个高亮。修正后在 PDF 绘制操作中按图形状态跟踪显式裁剪。碰到受显式裁剪影响的文字时保守降级，同时检查匹配矩形的渲染像素，均匀底色按无法确认可见文字处理。两张全白画布均无 PDF 高亮，授权摘录和定位失败提示仍可用。恢复图形状态后绘制的文字仍正常高亮。像素变化本身不足以确认字形，纹理与复杂混合效果的遮挡超出像素检查范围。复杂裁剪可能使可见文字也进入降级，授权摘录与原件入口仍可使用。
- N3：Chrome 回归通过授权原件 200/401/404、旧索引、取消、扫描件和移动端场景，26 个实际启动的 PDF worker 全部释放。快速改变缩放时，PDF.js 可能完成已开始的当前页文字提取，预览关闭时仍销毁该文档的 worker。
- 隔离验证在 Node v24.22.3 下执行。`npm run typecheck`、`npm run build -w @knowpilot/web`、`node --import tsx apps/web/tests/verify-pdf-preview.mjs` 均成功。Chrome 继续使用本地浏览器、合成 PDF 和临时 SQLite。本轮使用环回端口 4510/4511，并设置前文所列离线环境变量。
