### v1.3 独立审查修正

- N1/N3 补对照本人的持久化引用计数与笔记保留记录。零条引用且无记录的轮次仍可下载，历史记录中的引用数大于已保留记录数时，两种格式都只显示来源状态。合成测试在相同记录切换计数并校验实际文件字节、状态和标题正文标签遮蔽。
- N2 保留普通行内及多行公式、明确的顶层代码围栏，以及没有媒体或 HTML 标记的行内代码。格式识别不把非法的反引号围栏起始行当作代码区，围栏外的原件标签和 Markdown 图片仍降级为惰性文本。实际字节断言包括比较式、括号/方括号形式的公式以及代码中的链接形字符串。
- N2 补齐无外管线表格、超长表头和嵌套列表。超高表头以完整编号列名呈现，表格的重复行使用相同短编号，分页始终保留数据空间。修正后合成文件共 8 页，验证真实文字、单元格横向坐标、嵌套缩进与长表续页。与 Master Plan、本 Issue、此 Plan 和节点标准逐项复核，Ask 的共享表格语法无改动。

- N2/N3 Markdown 只对明确的顶层代码围栏保留原始内容。列表中遇到缩进变化时，其后的独立 HTML 和图像依照普通正文处理，避免在外部编辑器中自动加载。新增文件断言保存示例文字，并验证脱离列表后的媒体内容保持惰性。
- N3 复跑捕获了 390 像素下笔记表单的间歇横向溢出。限制查找和编辑表单的网格列及输入尺寸。Chrome 有时先报告新视口宽度、随后应用窄屏导航布局。浏览器确认导航收窄后，执行原有的无横向溢出断言。

### v1.4 独立复审说明

- Markdown 会中和可能被外部编辑器解释为活动内容的标签和图片标记。行内代码包含 HTML 标签或 Markdown 图片语法时，下载的 Markdown 也会替换相应字符。PDF 保留已验证的字面文本。超出常见表格行写法且无管线符的缺格行按正文读取。
- 二次复审核对引用数与追踪缺失、真实文件的公式与表格位置，以及 390 像素的原有横向溢出断言。两次浏览器定向复跑通过。
