## 查询与结果口径

- 正文搜索使用 `GET /api/v1/search?contractVersion=1&mode=keyword`。关键词及自然语言问题沿用服务端关键词索引、长问句词法扩展和相关性顺序。服务端候选范围支持 `material` 和单个 `documentId`。页面用资料类型筛选和「仅检索此资料」入口传递已支持的值。
- 现有上限 `SEARCH_MAX_LIMIT=50`。一次获取本次服务端排序的完整授权候选样本，按资料 ID 聚合，最佳片段决定该资料的顺序。导航在稳定样本中每页显示 8 份资料或 8 个片段。每次查询显示样本内去重后的文档数、实际片段数和 50 条上限。接口未给全库总数，界面不推算。
- 标题与台账快搜仍用 `/api/v1/quick-search`，保留原范围、每类最多 100 条、可用阅读器入口以及旧直达链接。授权文档标题分支支持可选的 `material` 和 `documentId`，在 SQL 中同标题或原文件名匹配条件一并应用，再排序并取前 100 条。只在筛选后的快搜结果达到上限时显示提示。正文样本计数不含标题或台账快搜。
- 当前查询的命中目录包含 `documentId`、`chunkId`、`sourceVersion` 和原文摘录，阅读器重新访问现有授权片段端点与核验摘录。React 将摘要作为文本并对命中分段着色。加载、范围无权、空结果、错误重试、索引待处理与旧索引各有提示。

## #8 导航交接契约

点击「基于此资料问答」后导航到 `/ask`。React Router 的 `location.state.searchHandoff` 载荷如下。

```ts
{
  version: 1
  query: string
  documentIds: string[]
  material?: Material
  documentId?: string
}
```

`documentIds` 是本次搜索会话中由用户明确选取的去重资料 ID。可跨当前候选样本的分页和视图选择，更换查询或范围时重置。`material` 和 `documentId` 是提交时正文查询的过滤条件。交接属于浏览器导航意图，URL 不含所选 ID，现有问答页尚未消费该载荷，也没有自动提问请求。接手端应校验版本、字段和 ID，以当前登录身份重新授权后才用于检索；服务端权限以现有授权层为准。
