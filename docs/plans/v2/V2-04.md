- N2 复用 `GET /api/v1/chunks/:chunkId`、原件下载和 V1 结构化精确台账查询。片段接口增量返回当前或历史块的来源版本。投稿、专利、大论文、人员台账使用既有查询授权。证据 GET 跳过浏览器缓存。禁止使用拒绝结果或历史答复里的旧正文填充面板。
- 匹配文档 ID、块 ID、版本及唯一逐字摘录后才标记原文。多处重复、无摘录、无法确认版本、版本变化均显示授权片段和提示。无访问权限、撤回、找不到及会话过期统一提示不可读取。桌面默认侧栏，可展开全屏。窄屏复用现有抽屉的焦点循环，关闭后归还焦点。支持来源列表和前后切换。
- 浏览器新增撤权复验后发现移到最后一条时原生禁用按钮可能失焦。将边界按钮改为 `aria-disabled` 并保留事件守卫，焦点保持，Escape 回归复验通过。
- 独立审查复现同一 PDF 页在索引流水线版本相同的 A、B 两次修订被错误拼作历史上下文。历史表只保存被替换的块，导入也没有修订批次标识，因此只展示被引用的历史块。当前片段保留真实同页上下文。历史页面的下载入口标注为当前原件。
