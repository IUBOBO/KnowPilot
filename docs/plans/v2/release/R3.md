# R3 安装、部署与配置文档 — 初始 Plan

状态为规划待审。负责人为发布协调者指定的任务负责人。[Issue #41](https://github.com/IUBOBO/KnowPilot/issues/41) · [发布 Master Plan](MASTER-PLAN.md) · [依赖图](DEPENDENCIES.json)

## 背景与任务边界

现有 README 说明开发启动，正式发布需要部署、配置、迁移入口和运行验证的连贯步骤。

整合开发启动与 Hono 同源托管、环境变量、HTTPS 和 Cookie 说明。优先复用已有部署文档，否则使用 docs/deployment.md。

## 输入、输出与依赖

- **输入** README.md、.env.example、锁文件、工作区 package scripts、服务配置与启动入口、已批准的发布计划。
- **输出** 部署与配置文档，以及可复现的隔离启动记录。
- **依赖** 发布规划 PR 经人工审查并合并。可与 R1、R2、R4 并行，汇总时与 R4 核对迁移和备份交接。
- **环境** 以规划 PR 合并后的实际主分支为文档实施起点。隔离验证使用合成资料、独立测试库、上传目录和端口。

## 实施步骤

1. 从锁文件安装并核对 Node 版本、前端构建、数据库目录与启动命令。
2. 在隔离环境说明开发联调、生产构建由 Hono 托管、健康检查、认证及 HTTPS/Cookie 配置。
3. 依据配置源码制作占位符配置说明，标明模型资料发送边界及权限要求。

## 测试用例

- R3-T1｜在干净候选环境执行 npm ci、npm run typecheck、npm run build -w @knowpilot/web。
- R3-T2｜使用合成凭据、独立 DB_PATH/UPLOAD_DIR 与回环端口，运行 npm run migrate，设置 SERVE_WEB=1 后执行 npm run start -w @knowpilot/server。核对 /health、认证、首页、页面路由及一个构建静态资源。

记录候选 SHA、操作或命令、实际结果、适用范围及脱敏证据。测试未执行时按原状态记录。

## 验收标准

- 命令和配置项与实际版本一致，隔离环境的构建、迁移、启动和页面检查有结果可审。
- 生产与开发运行方式可区分，公开示例仅包含占位符。

## 文件边界与恢复

构建与启动仅用于隔离验证。通过环境变量设置独立存储、地址和端口。禁止沿用生产 .env。发现启动或迁移失败时保留隔离日志并停止交付，核对实际版本、端口和数据路径。

## 交付物

部署与配置文档、命令和退出码记录、健康检查和页面验证证据。

## 进度记录

初始交付物随发布规划 PR 审查。实际分支、工作树、验证结果、偏差和发布文档 PR 在执行时回填。
